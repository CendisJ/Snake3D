SNAKE 3D – ANDROID PROJEKT

Toto je připravený zdrojový projekt Android aplikace. Obsahuje hru Snake 3D v assets/index.html a jednoduchý Android WebView obal.

DŮLEŽITÉ:
Toto zatím není hotový APK soubor. APK je potřeba sestavit v Android Studiu na počítači:
1. Nainstaluj Android Studio z oficiálního webu developer.android.com.
2. Otevři v Android Studiu složku Snake3D_Android_Project.
3. Počkej na dokončení Gradle Sync.
4. Zvol Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio vytvoří APK v app/build/outputs/apk/debug/.

Projekt potřebuje internet při prvním načtení Gradle závislostí. Pro instalaci APK používej jen vlastní sestavení a ověřené zdroje; pokud si nejsi jistý, požádej dospělého o pomoc.
